# Campus-Water-IQ RAG 知识库

本目录由 `Campus-Water-IQ_RAG_Demo与水利基础面试教程.md` 清洗整理而来，适用于演示与开发环境。

- `01` 至 `08`：从原文清洗的校园水务、设备、水质、SWMM、水库、水文和数据质量基础。
- `09`：校园智慧水务系统架构与业务对象。
- `10`：水表数据字典、时间字段和统计口径。
- `11`：设备、网关、网络和协议分层排查。
- `12`：漏损识别、计量边界和基线分析。
- `13`：水质监测点、采样和人工复核流程。
- `14`：降雨、产流、汇水区和城市排水。
- `15`：SWMM 建模实践与结果审查。
- `16`：水库调度场景、约束和方案比较。
- `17`：宿舍、食堂、实验室、绿化和场馆节水场景。
- `18`：RAG 路由、来源、拒答和写操作确认策略。
- `19`：水务术语词典与高频问答。
- 校园流程、设备编码和处置建议均为演示资料，不是正式制度或生产规程。
- 涉及公共安全、阀门控制、水质结论或报修提交时，必须人工复核与确认。

测试问题和预期路由见 `src/test/resources/rag/evaluation-set.jsonl`。
