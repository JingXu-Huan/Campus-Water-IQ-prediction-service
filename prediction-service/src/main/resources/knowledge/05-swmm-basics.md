# SWMM 基础知识

## 定义与用途

SWMM 是用于城市降雨径流、排水管网水力过程和水质过程模拟的模型，可进行单场或连续降雨模拟、地表产流、管网输送、节点积水、调蓄、LID 和污染物过程分析。

## 典型对象

- 雨量计（Rain Gage）：提供降雨时间序列。
- 子汇水区（Subcatchment）：接收降雨并产生地表径流的区域；常见参数有面积、坡度、不透水率、宽度、粗糙系数、洼蓄量和下渗参数。
- 节点（Junction）：管网连接或汇合点。
- 管渠（Conduit）：输送水流的管道或渠道。
- 出口（Outfall）、蓄水单元（Storage Unit）、泵（Pump）、孔口/堰等调节设施。
- LID：雨水花园、透水铺装、绿色屋顶等低影响开发设施。

## 过程、输入与输出

水文过程：降雨 → 截留/洼蓄/下渗/蒸发 → 地表径流 → 节点和管网。水力过程关注径流在节点和管渠之间传播，可描述回水、顶托和压力流等。

输入通常包括降雨、汇水区、地形、土地利用、不透水率、管网几何、节点高程、边界、下渗和粗糙参数。输出包括产流量、峰值、径流总量、节点水深和溢流、管道流量及充满度、出口过程和 LID 效果。

## 建模与率定

明确目标，划分子汇水区，建立拓扑，导入降雨并设置参数和边界，运行后检查质量守恒误差。率定是用观测数据调整参数使模拟接近实际；验证应使用另一组数据。模拟结果不能替代现场调查。

## 面试式回答模板

### SWMM 中子汇水区是什么？

子汇水区是接收降雨并形成地表径流、最终汇入某个节点或出口的区域。建模时要描述面积、坡度、不透水率、地表粗糙、洼蓄和下渗等属性。它不是一段管道，也不等同于行政区域。

### 为什么要率定和验证？

模型参数通常不能只靠经验确定。率定使用观测资料调整参数，使模拟过程接近实际；验证使用独立事件检查模型是否具有泛化能力。只在同一场降雨上不断调参，不能证明模型可靠。

### 复杂模型一定更好吗？

不一定。复杂模型需要更多高质量数据和参数，错误的拓扑或不可信的输入会让结果看起来精细但更难解释。应先满足目标和数据条件，再增加复杂度。

## 结果审查清单

```text
[ ] 降雨单位、时区和时间步长正确
[ ] 子汇水区面积没有重复
[ ] 节点和管渠拓扑连通
[ ] 节点高程和出口边界合理
[ ] 参数来源和假设有记录
[ ] 连续性误差已检查
[ ] 峰值、总量、过程线和持续时间都已查看
[ ] 率定数据与验证数据相互独立
[ ] 方案结论已标注不确定性
```
