# 水库调度场景与方案分析（演示版）

## 1. 场景描述

某调蓄水库需要在连续若干时段内协调防洪、供水、生态下泄和发电。调度员已知当前库容、预测入流、蒸发损失、下游安全流量和各目标需求，但入流预测存在不确定性。

## 2. 状态与决策

状态可以包含时段、库容、水位、入流预测、下游需求、预留防洪库容和设备可用性。决策通常是本时段下泄量、供水量、发电流量或是否预泄。每个决策都要经过库容和流量约束检查。

## 3. 水量平衡

`S_next = S_now + Inflow - Release - Spill - Evaporation - Seepage`

若 `S_next` 超过最大库容，多余部分可能成为弃水；若低于死库容，方案不可行或需要触发供水风险。实际模型还需明确时间步长、单位和水位-库容曲线。

## 4. 暴雨前预泄

预泄可以增加防洪库容，但会减少当前可供水量并可能影响下游安全。判断预泄时需要结合降雨和入流预测置信度、下游流量、生态下泄、库容曲线和预警等级。不能只依据一个预测值自动执行。

## 5. 供水冲突

防洪要求保留空间，供水要求保持较高库容，生态要求维持最低下泄，发电目标可能偏好某些流量。目标之间冲突时，先按正式调度规则确定优先级，再比较可行方案的代价。

## 7. AI 可以做什么

AI 可以汇总预测、解释规则、比较多个已校核方案、检索历史案例和生成调度报告。AI 不应绕过审批、修改正式调度规则或直接控制闸门、泵站和其他关键设施。
